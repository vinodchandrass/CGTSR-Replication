# Data Availability

This repository contains the compact empirical artifacts required to
inspect the reported CGTSR results.

The complete per-test coverage-characterisation data are intentionally
not included in the initial lightweight repository because the twelve
JSON coverage maps are substantially larger than the summary artifacts.

Raw coverage.py databases, virtual environments, cached packages,
temporary execution directories, and third-party project source trees
are not distributed in this repository.

The evaluated third-party projects are identified by project and
release in metadata/subject_releases.csv.
